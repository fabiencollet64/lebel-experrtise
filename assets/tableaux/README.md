# Tableaux du domaine public à déposer ici

Les quatre fichiers sont déposés (versions Wikimedia Commons à 960 px de large ; une version plus grande, 1600 px ou plus, améliorera le rendu sur grand écran). La maquette affiche un emplacement légendé tant qu'un fichier n'existe pas, puis la
peinture dès qu'il est déposé sous le nom attendu (traitement automatique : désaturation
de 25 % et voile du bleu finance à 20 %). Rechercher les œuvres sur Wikimedia Commons et
privilégier un fichier d'au moins 1600 px de large, compressé en JPEG qualité 80.

| Fichier attendu | Œuvre | Section | Symbolique |
|---|---|---|---|
| `vocation-saint-matthieu.jpg` | *La Vocation de saint Matthieu*, Caravage, 1599-1600 | Hero | L'appel, l'argent compté |
| `mercure-et-argus.jpg` | *Mercure et Argus*, Rubens, vers 1636-1638 (Prado) | Acquisition | Hermès, dieu des échanges |
| `le-preteur-et-sa-femme.jpg` | *Le Prêteur et sa femme*, Quentin Metsys, 1514 (Louvre) | Financement | Ploutos, la richesse pesée |
| `les-changeurs.jpg` | *Les Changeurs*, Marinus van Reymerswaele, XVIe siècle (plusieurs versions existent : vérifier le musée de celle retenue) | Autres missions | Thot, les comptes tenus |

Les légendes (titre, artiste, date, lieu de conservation) sont déjà écrites dans `index.html`
sous chaque image ; les adapter si une autre version de l'œuvre est retenue.
